# 🌸 Bloom - Self Care & Mood Tracker

Bloom is a simple and aesthetic self-care website designed to help users track their mood, water intake, and daily self-care habits in a soft and calming environment 💖

---

## ✨ Features

- 😊 Mood Tracker (Happy, Calm, Sad, Angry, Tired)
- 💧 Water Intake Counter (up to 8 cups)
- 🌸 Self Care Checklist
- 💬 Personalized motivational messages
- 🎨 Soft pastel UI design
- 📱 Simple and responsive layout

---

## 💡 Project Idea

The idea behind Bloom is to create a safe digital space where users can:
- Check in with their emotions
- Stay hydrated
- Track small self-care habits
- Feel supported with positive messages
